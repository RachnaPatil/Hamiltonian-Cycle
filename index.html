Hamiltonian Cycle

A Hamiltonian cycle visits every vertex exactly once and then returns to the starting vertex. Learn the idea, see the backtracking algorithm, and try it on your own graphs.

Explore Interactive Demo

Theory

Definition

Imagine cities connected by roads. A Hamiltonian cycle is a round trip that visits every city exactly once and ends in the city where you started. Formally, it is a cycle in a graph G = (V, E) that contains every vertex of V exactly once.

Path vs. Cycle

Hamiltonian Path: visits every vertex exactly once; start and end can differ.

Hamiltonian Cycle: a Hamiltonian path whose last vertex is also connected back to the first vertex.

Every graph with a cycle has a path, but not the other way round.

Real-World Applications

  • Delivery and route planning (Travelling Salesman Problem)
  • Circuit board drilling and wiring
  • DNA fragment sequencing
  • Scheduling and tour design

Time Complexity

Backtracking tries vertex orderings, so in the worst case it explores about (n − 1)! arrangements, written as O(n!). The problem is NP-complete, so no known fast algorithm exists for all graphs. Pruning (skipping used vertices and non-edges) makes it faster in practice.

Algorithm: Backtracking

HamiltonianCycle(G, n):
  path[0] ← vertex 0       // fix the start
  visited[0] ← true
  return Solve(1)

Solve(pos):
  if pos = n:
      return G[path[n-1]][path[0]] = 1
  for v ← 1 to n-1:
      if not visited[v] and G[path[pos-1]][v] = 1:
          path[pos] ← v;  visited[v] ← true
          if Solve(pos + 1) then return true
          visited[v] ← false             // backtrack
  return false

How it works

  1. Start at vertex A (a cycle can start anywhere).
  2. Pick an unvisited neighbour of the last vertex and add it to the path.
  3. Repeat until all n vertices are placed.
  4. If the last vertex connects back to A, a cycle is found.
  5. If stuck, remove the last vertex (backtrack) and try another neighbour.
  6. If every option fails, no Hamiltonian cycle exists.
Time: O(n!)Space: O(n)

Space: the path, visited array and recursion stack each use O(n) (the adjacency matrix itself is O(n²)).

Examples

Example 1: Has a cycle ✔

Vertices A–E form the outer ring A-B-C-D-E-A, so every vertex is used once and we return to A. The extra edge B–D is not needed.

Example 2: No cycle ✘

D and E each have only one neighbour (A). A cycle needs every vertex to have at least two edges, so no cycle can pass through D or E.

Example 3: Has a cycle ✔

This 6-vertex graph has a hexagon A-B-C-D-E-F-A plus chords. Chords give more choices, but the hexagon alone is enough.

Example 4: Path only ✘

A-B-C-D is a Hamiltonian path, but D has just one edge, so it cannot return to A. A path exists; a cycle does not.
